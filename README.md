# 你好，我是大气包 视觉设计师 / 提示词工程师

｜ 把创作经验、视觉判断与重复操作，沉淀成可复用的提示词库、Agent Skills 和视觉工作流。

我不只做视觉内容，也不只做一张海报或一个 Figma 模板。我在探索的是：怎样把内容创作、视觉设计、素材处理、提示词、组件规则和人工判断，拆成 AI 可以协作、人可以检查、以后还能持续迭代的系统。

餐饮海报是我目前正在深入实践的一个方向；未来这里也会记录更多海报提示词库、视觉生成方法、设计模板和创作自动化工作流。

---

## What I Build / 我在做什么

- **Poster prompt libraries** — 将海报风格、构图、字体、色彩、材质与画面规则整理为可迁移的提示词系统。
- **Agent Skills** — 把内容、设计与交付经验封装成可调用、可复用、可检查的 Skills。
- **Visual workflows** — 用 Figma、AI 图像生成和组件系统，搭建从素材到成品的视觉生产流程。
- **Design systems** — 将组件、版式、变量、图层保护和验收规则沉淀为可维护的模板。
- **Creative experiments** — 持续测试哪些创作环节适合交给 AI，哪些关键判断应该始终留给人。

## Current Focus / 当前实践

## How I Work / 我的工作方式

- 从真实的创作摩擦开始，而不是从抽象功能开始。
- 把一次做对的经验，整理成下一次可以直接调用的系统。
- 让 AI 处理重复劳动，把审美、判断与最终控制留给人。
- 优先做可检查、可维护、可持续迭代的工作流。

# 菜谱海报提示词库

这里保存可直接复用的中文菜谱海报提示词系统。每个文件都将数据、结构与视觉职责拆开，并给出可执行的组合版本。

| 提示词系统 | 用途 | 状态 |
| --- | --- | --- |
| [S1 + F1｜复古绿调完整菜谱海报](./s1-f1-recipe-poster.md) | 用菜名或菜品参考图生成单张完整菜谱海报 | S1、F1 常用 |
| [D1 + S7 + F12｜复古家常菜标签海报](./d1-s7-f12-label-poster.md) | 用菜品参考图、结构线稿与风格图生成单张标签海报 | D1、S7 测试 / F12 常用 |

## 组合原则

- `D`：只处理菜品信息检索、字段标准化与一致性校验。
- `S`：只定义画布、版式、信息层级、图片边界与安全区。
- `F`：只定义配色、字体、材质、装饰与图像表现。

提示词系统统一按“`数据（如需要） + 结构 + 风格｜交付物`”命名。`S1 + F1` 是完整菜谱海报组合；`D1 + S7 + F12` 是固定单菜标签海报组合。
